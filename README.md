
# 🌿 Plant Disease Classification & Web App

A Deep Learning-powered web application that identifies plant diseases from leaf images to help farmers diagnose crop issues early.

## 🚀 Live Demo
🔗 **[Click here to view Live App](YOUR_WEBSITE_LINK_HERE)**

## ✨ Key Features
* **Disease Detection:** Classifies plant leaf images across multiple species and diseases.
* **Web Interface:** Interactive UI for uploading leaf images and viewing instant predictions.
* **Deep Learning Model:** Built using CNN / Transfer Learning in TensorFlow/PyTorch.

## 🛠️ Tech Stack
* **Machine Learning:** Python, TensorFlow / Keras, OpenCV, Google Colab
* **Frontend / Web:** HTML, CSS, JavaScript (or Flask / Streamlit)
* **Dataset:** PlantVillage Dataset (Kaggle)
